# propShield

An AI-powered assistant helping Indian renters and property buyers make confident decisions.

## About

propShield helps users understand rental and sale agreements, identify risks, and prepare for conversations with property lawyers — all in plain language, no legal jargon.

## Tech Stack

- **Vite** + **React 18** + **TypeScript**
- **Tailwind CSS** + **shadcn/ui**
- **Supabase** (backend & edge functions)
- **TanStack Query**

## Features

- 📄 **Document Analysis** — Upload and understand rental/sale agreements
- ⚠️ **Risk Awareness** — Know what to verify before signing
- 📍 **Location Insights** — Compare areas based on commute, budget & lifestyle
- ⚖️ **Lawyer Preparation** — Generate smart questions before consulting a lawyer
- 💬 **AI Chat** — Conversational assistant for all property queries

## Getting Started

```sh
# Install dependencies
npm install

# Start dev server
npm run dev

# Run tests
npm test
```
